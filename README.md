# Omnisight AI — Business Visibility & Website Audit Platform

> **"See how the internet — and AI — sees your business."**

Omnisight AI is a production-ready SaaS platform engineered to audit website presence, machine legibility, and Generative Engine Optimization (GEO) discoverability across Google, ChatGPT, Gemini, Perplexity, and local search systems.

---

## 🚀 Quick Start

### 1. Install & Setup
```bash
npm install
npx prisma db push
npx tsx prisma/seed.ts
```

### 2. Run Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## ⚙️ Key Architecture & Features

### 1. Multi-Agent Analysis Pipeline
The platform separates business auditing into modular evaluators:
1. **DOM & Technical Crawler**: Fast Cheerio parsing of titles, H1-H3, word counts, SSL, meta tags, and structured schemas.
2. **Website Clarity Analyzer**: Immediate hero value proposition comprehension, above-the-fold communication.
3. **AI Visibility & Machine Readability Analyzer**: Evaluates JSON-LD schema entity clarity, service taxonomy, and AI question-answering readiness.
4. **Search & Local Presence Analyzer**: NAP (Name, Address, Phone) consistency, postal indicators, geographic coverage.
5. **Content & Authority Analyzer**: Topical depth, service specialization pages, customer question answering.
6. **Trust & Credibility Analyzer**: Customer reviews, testimonials, licenses, privacy policies, SSL.
7. **Conversion Readiness Analyzer**: Click-to-call, WhatsApp links, quote request accessibility.
8. **Synthesis & Prioritized Action Plan**: Fix Now (Immediate), Fix Next (Short-term), Optimize Later.

### 2. Two-Stage Business Model & Conversion Funnel
- **Stage 1 (Free Audit)**: Instant Business Visibility Score (0–100), category score gauges, top strength, top warning, and blurred curiosity teasers (8 additional issues locked, competitor gaps locked, action plan locked).
- **Stage 2 ($10 Paid Full Report)**: Unlocks full multi-agent diagnostic, copy-paste JSON-LD Schema generator, competitor comparison matrix, Prioritized Action Plan, and printable executive PDF export.
- **Backend High-Ticket Funnel ("Want Us To Fix It?")**: Direct lead generation capture routing high-intent prospects to your agency services ($1,500–$5,000 redesigns and GEO optimization).

### 3. Admin Control Center
- Real-time KPI telemetry: Audits performed (Free vs Paid), gross revenue, conversion rate %, AI costs.
- **Dynamic Price Testing**: Change report price ($10, $15, $19, $20, $29) on the fly without redeploying code.
- **Dynamic Category Weight Sliders**: Calibrate scoring formula in real-time.
- **Developer Test Mode Switch**: 1-click test unlock bypasses live credit card requirements during development and testing.
- **Agency CRM**: View and manage inquiries submitted through the "Want Us To Fix It?" module.

### 4. Programmatic Industry Landing Pages
- `/services/roofing`
- `/services/real-estate`
- `/services/saas`
- `/services/construction`
Each page contains industry-specific AI ranking challenges and signals to win.
